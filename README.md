# 按刻 · Presslet

在 Mac 触控板上重按，滑向动作，松手执行。

按刻是一个原生 macOS 小工具。它会根据前台 App，在指针旁展开玻璃动作菜单，支持发送快捷键、打开应用或网址，以及运行已有的快捷指令。首页、按 App 配置、指针浮层和诊断窗口都保留独立入口。

## 玻璃展开菜单

重按达到阈值时，动作从指针周围展开。继续保持按住，向动作轻移指针，松手即可执行；回到中央或移出菜单范围后松手取消。每个菜单支持 1 至 9 个动作，三个以内沿固定方向展开，更多动作环绕排列。

玻璃卡片会随按压力度和指针方向轻微形变，选中动作也会响应指针移动。macOS 26 起使用原生液态玻璃，较早系统使用毛玻璃；展开与收起动画会跟随系统的“减少动态效果”和“减少透明度”设置。

## 动作输入

每个动作可声明“无需内容”“选中文字”“选中文件”或“选中图片”。在“管理 App 动作…”中选择输入要求，按刻会将当前 App 的选中内容交给对应动作。旧配置按“无需内容”读取，原有动作保持可用。

| 动作 | 输入的用途 |
| --- | --- |
| 键盘快捷键 | 检查是否满足输入要求，再向原 App 发送快捷键；不会复制或粘贴内容 |
| 打开应用 | 将选中的文件交给指定应用打开；文字及网址目标不支持内容输入 |
| 运行快捷指令 | 将文字以 UTF-8 文件、文件以原路径传给快捷指令的输入 |

选中文字通过辅助功能读取。按刻只在当前 App 配置了需要内容的动作时观察选区，并在手势开始时确定来源；不会读取剪贴板。Finder 文件通过系统自动化接口获取，在 Finder 配置页点击“允许读取 Finder 选中文件…”可发起授权。未授权、未选中或应用不提供选区时，相关动作留在原位并灰显。

快捷指令需在其内部接收并处理“快捷指令输入”。按刻会接收它返回的文字结果；动作完成、失败或取消时清理为本次文字输入创建的临时文件。原文件不复制、不删除。图片输入根据文件扩展名判断，转换能力由你配置的动作决定。

选区读取取决于目标 App 提供的辅助功能信息。Finder 选区需要额外的自动化授权；未取得内容时，菜单会说明原因。

## 安装与开始使用

需要 Apple Silicon Mac、macOS 14 或更新版本，以及支持 Force Touch 的触控板。当前发行包为 arm64。跨 App 重按和系统动作接管已在开发用 Mac 的 Edge 中实测；其他 App、设备与系统版本需要进一步使用验证。

1. 从 [Releases](https://github.com/zhangxiao91/presslet/releases/latest) 下载发行包，解压后将 `Presslet.app` 拖入“应用程序”。如果使用 DMG，打开后拖入其中的“应用程序”文件夹。
2. 打开按刻，根据首页提示前往“系统设置 → 隐私与安全性 → 辅助功能”，允许按刻控制输入，再回到按刻重试连接。
3. 点击“管理 App 动作…”，选择 App，编辑菜单后保存。
4. 回到目标 App，按下触控板并继续加力。菜单展开后保持按住，滑向动作，再松手执行。回到中央后松手可取消，也可按 Esc 关闭。

当前发行包采用本地 ad-hoc 签名，尚未通过 Apple 公证。macOS 可能显示安全提示；确认下载来源后，可在“系统设置 → 隐私与安全性”中查看系统提供的打开选项。更新或移动应用后，如果系统仍显示已授权但连接失败，可在辅助功能列表中移除旧条目，再添加实际使用的这一份 App。

关闭首页开关可暂停跨 App 重按；退出应用会停止接管。关闭首页窗口后，按刻仍可从菜单栏打开。

## 按 App 配置动作

初始配置包含“通用”、Microsoft Edge 和 Finder。没有单独配置的 App 使用通用菜单；为某个 App 关闭菜单后，该 App 会保持关闭。每个菜单最多启用 9 个动作，可调整顺序、名称和启用状态。

| 动作类型 | 内容示例 | 用法 |
| --- | --- | --- |
| 键盘快捷键 | `cmd+l`、`cmd+shift+g` | 将快捷键发送到呼出菜单的 App |
| 打开 App 或网址 | `com.apple.calculator`、`https://www.apple.com` | 可通过“选择应用…”填写，或输入应用标识、完整 `.app` 路径、HTTP/HTTPS 网址 |
| 运行快捷指令 | 已有的快捷指令名称 | 在系统“快捷指令”App 中先创建，再填写完全相同的名称 |

快捷键由 `cmd`、`option`、`ctrl`、`shift` 中的修饰键，加一个字母、数字、方向键或支持的功能键组成。动作会使用目标 App 自己的快捷键含义。

为某个 App 开启“接管系统重按”，可让按刻处理重按并避免同时出现系统查词或预览。Edge 预设默认开启，通用和 Finder 默认保留系统重按。不同 App 对重按的处理可能不同，可分别选择。

配置窗的预览可以检查动作顺序和展开效果；发送快捷键的完整效果请回到目标 App 通过重按验证。快捷指令可能要求额外的系统权限，按其自身提示处理。

## 其他入口

| 快捷键 | 功能 |
| --- | --- |
| `Control + Option + M` | 预览动作菜单 |
| `Control + Option + 空格` | 在指针旁打开浮层，再在浮层上重按 |
| `Command + ,` | 打开按 App 配置 |

通过配置窗或快捷键打开预览时，可用鼠标点击动作，或按对应数字键执行；方向键选择后按 Enter 执行，空格回到中央，Esc 关闭。

首页的“诊断…”入口保留力度显示，方便检查触控板是否识别到重按。日常使用无需打开。

## 配置与权限

动作配置保存在本机：

```text
~/Library/Application Support/dev.zxlab.Presslet/actions.json
```

点击“保存”后生效，退出重开会重新载入。首次运行正式版时，如果新目录尚无配置，会读取测试版 `dev.zxlab.ForcePressBlockTest/actions.json` 中有效的旧配置，并保存到新目录；旧文件保留。配置损坏时会提示错误并暂用预设，原文件不会在载入时被覆盖。

辅助功能权限用于接管重按和发送快捷键。跨 App 输入监听由系统事件接口提供；若系统提示输入监控权限，可在同一隐私设置页面中管理。应用配置在本机读写；打开的网址和运行的快捷指令由相应 App 处理。

## 从源码编译

源码按四个组件分工：`PressureInputManager` 接收输入，`ContextResolver` 确定本次操作的选中文字或文件，`ActionProvider` 选择当前 App 的动作，`MenuPresenter` 显示菜单并返回选择。`App.swift` 连接这些组件，最终动作交给 `ActionExecutor` 执行。

跨 App 事件在专用 run loop 线程中接收。回调按已载入的规则决定是否拦截，将事件放入有容量限制的缓冲区，再按顺序交给主线程处理。菜单显示和选区读取安排在回调之外；AX 读取另用后台串行队列。输入积压或连接中断时会取消本次重按，等待下一次按下，避免留下半个手势继续执行动作。

构建需要 Apple Silicon Mac，以及包含 macOS 26 SDK 的 Xcode 26 或对应 Command Line Tools；生成的应用支持 macOS 14 及更新版本。项目使用 Swift、AppKit、Core Graphics 与 Carbon，不需要第三方包。

```sh
bash scripts/test.sh
bash build.sh
```

应用生成在 `build/Presslet.app`。构建脚本默认使用 ad-hoc 签名，也可通过 `CODESIGN_IDENTITY` 指定本机签名身份。

```sh
bash scripts/package.sh
bash scripts/package.sh --dmg
```

打包前会运行测试并重新构建，发行文件生成在 `dist/`。`--dmg` 会同时生成 ZIP 和 DMG。构建产物与本机配置均不纳入源码仓库。

测试覆盖输入顺序、力度状态、菜单选择、配置兼容、选区读取的调度，以及动作参数传递、本地进程执行和临时文件清理。真实力度、系统动作接管与窗口动画需要物理触控板检查，参见[手动检查说明](docs/manual-testing.md)。
