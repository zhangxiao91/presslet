# 手动检查

真实的触控板重按、系统权限和动画需要在 Mac 上检查。自动测试负责力度状态、菜单触发和配置读写；它们不能替代硬件输入。

## 首次运行

1. 将打包后的 App 放入“应用程序”并打开。
2. 确认首页只保留运行状态、App 动作与常用入口，窗口缩放比例下文字清楚，控件没有遮挡。
3. 允许辅助功能，重试连接，确认首页显示运行中。关闭再打开首页开关，检查暂停与恢复。

## 重按与菜单

1. 在 Edge 配置中启用菜单和“接管系统重按”，保存。
2. 切回 Edge，在单词处重按。确认菜单开始显示，系统查词没有同时出现；松开后选择“地址栏”，检查地址栏是否选中。
3. 分别用 Esc、点击外部和执行动作关闭菜单，检查收起动画。连续重按时，不应出现同一次按压重复打开菜单。
4. 检查普通点击、拖动和滚动；关闭按刻或暂停后，检查系统重按行为是否恢复。
5. 开启系统“减少动态效果”，检查菜单仍可正常开关，缩放减少。
6. 使用 `Control + Option + 空格` 打开指针浮层，在浮层上重按并选择动作。

## 动作与保存

1. 添加一个 App，调整动作顺序、名称和启用状态，保存后退出重开，检查内容是否保留。
2. 通过真实重按验证快捷键；通过打开计算器或网址验证打开动作。
3. 在“快捷指令”App 中创建一个只返回文字的指令，将同名指令填入菜单，检查运行结果。
4. 关闭某个 App 的菜单，确认它不会退回通用菜单；移除该 App 的独立配置并保存后，应恢复使用通用菜单。

## 旧配置读取

新目录没有 `actions.json` 时，启动会尝试读取旧目录中的有效配置。检查新目录保存成功、旧文件仍在、原有动作未丢失。新目录已有配置时应优先读取新文件。损坏文件应显示错误，载入操作不得覆盖原文件。

请在开发环境中使用备份或临时配置验证损坏文件，不要直接破坏日常配置。
